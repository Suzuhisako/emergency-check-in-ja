# 災害時・安否確認Webアプリ (Disaster Status Check App)

緊急時や大規模災害発生時に、オフライン環境（SMS / BLEメッシュ）や最小限の操作で家族間の安否情報を迅速に共有・一括送信するための軽量Webアプリケーションです。

---

## 🌟 主な機能 (Key Features)

- **ワンタップ安否ステータス更新 (Quick Status Update)**
  - 「無事」「移動中/避難中」「避難完了」「要救助」の4段階ステータスを即座に切替。
  - 現在地や補足メモを自由に入力可能。

- **スマートSMS共有 (SMS Template & Recipient Selection)**
  - 定型メッセージを自動生成し、スマートフォンの標準SMSアプリへ連携。
  - 送信先（家族メンバー）をチェックボックス形式で柔軟に一括・個別選択可能。

- **家族安否情報ボード (Family Status Board)**
  - 家族個々の安否状況、最終確認場所、バッテリー残量、受信経路を一覧表示。
  - メンバーの個別追加・編集・削除機能。

- **SMS取り込み機能 (SMS Data Import)**
  - 受信したSMSテキストを解析し、家族ボードへ手動/自動反映。

- **ローカルファースト設計 (Local-First & Offline Ready)**
  - データはすべて端末内（`localStorage`）に安全に保存。外部サーバーへの通信なしで動作。
  - PWA感覚で「ホーム画面に追加」してスタンドアロンアプリとして利用可能。

---

## 📱 使い方・設置手順 (Usage Instructions)

### 1. アプリの起動とホーム画面追加
1. 提供されたWeb URLをスマートフォンのブラウザ（iOS: Safari / Android: Chrome）で開きます。
2. ブラウザメニューの **「ホーム画面に追加」** を選択すると、通常のスマホアプリと同様の1タップ起動が可能になります。

### 2. 家族メンバーの初期登録
1. 画面下の **「家族の安否情報」** セクションへ移動します。
2. **「+ 追加」** ボタンを押し、家族のお名前・電話番号を登録します。
3. 登録されたメンバーは、送信先チェックボックスに自動的に反映されます。

### 3. 安否情報の送信
1. 自らのステータスボタン（無事、移動中など）を選択し、必要に応じてメモを入力します。
2. 送信したい家族のチェックボックス（または「全員を選択」）をチェックします。
3. **「SMS送信」** ボタンをタップすると、標準SMSアプリがメッセージ入力済みの状態で起動します。

## 🛠 技術スタック (Tech Stack)

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **UI Framework:** Bootstrap 5 (Dark Mode Theme)
- **Data Persistence:** `localStorage` (Web Storage API)
- **Integrations:** Universal `sms:` URI scheme

---

## 🔒 プライバシーとセキュリティ (Privacy & Security)

- **完全ローカル保存:** 入力された名前、電話番号、位置情報などのデータはすべてユーザー自身のブラウザ内にのみ保存されます。
- **追跡・ログの排除:** 外部トラッキングツールやサードパーティサーバーへのデータ伝送は一切行われません。
