#  緊急時家族安否確認アプリ (Emergency Family Check-In)

災害、大規模停電、回線混雑の発生時に、家族間で素早く安否情報を共有するためのオフライン対応Webアプリ (PWA) です。

非常時には特定の通信機能が制限されたり、回線が著しく混雑することがあります。本アプリは、安否状況・GPS位置情報・必要な支援内容をコンパクトな定型文に自動整形し、**SMS、LINE、メール、各種メッセージングアプリ**へ即座に引き継いで送信できるようにサポートします。

---

##  主な機能

-  **完全オフライン対応 (PWA):** ネット接続が途切れた状態でも、スマホのブラウザ上でそのまま動作します。
-  **マルチアプリ連携:** 定型化した安否メッセージをワンタップでSMS、LINE、メール、各種SNS・シェア機能へ連動。
-  **ワンタップGPS取得:** 現在地の位置情報（緯度・経度）を自動で取得し、メッセージに添付。
-  **ホーム画面への追加:** スマホにインストールして独立したアプリとして起動可能。
-  **プライバシー保護:** 中央サーバーへのデータ送信は一切ありません。連絡先や位置情報は端末内のみに保存されます。

##  デモ・インストール方法

スマホのブラウザから直接アクセス・インストールしてご活用ください。

| エディション | URL | インストール方法 |
| :--- | :--- | :--- |
| **安否確認アプリ** | [アプリを開く](https://suzuhisako.github.io/emergency-check-in-ja/index.html) | **PWAアプリとして追加** (ホーム画面に追加) |

---

###  スマホへの追加手順

1. **Android (Chrome):** `index.html` を開く ➔ メニュー (`⋮`) ➔ **「アプリをインストール」** または **「ホーム画面に追加」** を選択。
2. **iOS (Safari):** `index.html` を開く ➔ 共有アイコン (⬆️) ➔ **「ホーム画面に追加」** を選択。

> **ポイント:** ホーム画面に追加（PWA化）しておくことで、災害時に圏外（オフライン）になっても即座にアプリを起動できます。

##  メッセージフォーマットと送信例

どのようなアプリや回線経由でも正確かつ最小限のデータ量で伝達できるよう、以下のフォーマットで出力します。

### 定型フォーマット

[状態] | [氏名] | [現在地 / GPS] | [メッセージ / 必要な支援] | [タイムスタンプ]
